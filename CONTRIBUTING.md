# Contributing

Use Node.js 22 or 24 and npm. Run `npm ci --ignore-scripts` then `npm run verify`.
Submit focused changes with a deterministic offline regression test and updated documentation.
Use synthetic fixtures only. Do not include credentials, private conversations or captured continuation state.
Contributions must be yours to submit under MIT; preserve any third-party notices and explain provenance.
Do not publish packages or create releases as part of a normal pull request.
