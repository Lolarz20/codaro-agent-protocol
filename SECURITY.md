# Security

Report vulnerabilities through [private vulnerability reporting](https://github.com/Lolarz20/codaro-agent-protocol/security/advisories/new).
If unavailable, open an issue requesting a private reporting channel without disclosing the vulnerability.
Do not paste credentials, proprietary source, private prompts, signatures or unredacted responses.
Version 0.1.x is the initial supported line. Maintenance and response are best effort; no response SLA is promised.
See the README and security documentation for the precise scope and limitations.
